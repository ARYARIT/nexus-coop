# NexusMC Coop Helper (Fabric / Quilt, Minecraft 1.21 – 1.21.1)

Мод внутри игры. Если лаунчер NexusMC не передал параметры `-Dnexus.coop=...`, он ничего не делает.
Когда мир загрузился, мод сам открывает его для сети на порту от лаунчера (только 127.0.0.1),
выключает проверку Mojang для этого мира и пишет `nexus-session.json` рядом с игрой.

## Как собрать (без установки Java)

Workflow собирает сразу много версий:

- Fabric/Quilt: 1.16.5, 1.18.2, 1.19.2, 1.19.4, 1.20.1, 1.20.4, 1.20.6, 1.21.1, 1.21.4, 1.21.8
- NeoForge: 1.21.1, 1.21.4, 1.21.8

1. Залей **всё содержимое этой папки** в репозиторий GitHub с сохранением папок (в том числе `neoforge/` и `.github/workflows/build.yml`).
2. **Actions** → `build-coop-helper` → **Run workflow**. Подожди 10–20 минут.
3. Часть версий может не собраться (в списке они красные), остальные соберутся. Это нормально.
4. Внизу страницы запуска скачай архив **`nexus-coop-all`**: в нём готовые jar с правильными именами (`nexus-coop-fabric-1.20.1.jar`, `nexus-coop-neoforge-1.21.4.jar` и т.д.).
5. Положи все jar в `resources/coop/` проекта лаунчера. Лаунчер сам выберет нужный по версии и загрузчику. Для версии без jar совместная игра просто не включается.

Если нужная версия красная, открой её лог и пришли мне последние строки с ошибкой. Версии, которые вам не нужны, можно удалить из `build.yml` (строки в `matrix`).

## Для готовой версии лаунчера (.exe)

В настройках electron-builder добавь папку в extraResources:

    "extraResources": [{ "from": "resources/coop", "to": "coop" }]

## Как проверить

1. Запусти сборку Quilt или Fabric на 1.21.1.
2. В `latest.log` сборки найди строку `World opened for friends on 127.0.0.1:...`.
3. В Supabase в `game_sessions` у этой сессии `lan_ready` станет `true` без переключателя `nexusCoopDev`.
4. Выйди из мира в меню, `lan_ready` станет `false`. Зайди в мир снова, станет `true`.
